# qnGatherer

Gathering database for herbs, ore, fishing and treasure – **in development**.

Back to the [overview](README.md) · German: [Deutsch](../de/qnGatherer.md)

## Current state (0.1.0)

Version 0.1.0 contains only the data core: the saved variable `qnGathererDB` and the rules for
storing gathering nodes, fishing areas, zone skill ranges and catches. The addon does **not collect
or show anything yet**, has no options page and no slash command.

Planned in the next versions: recording nodes while gathering, icons on the world map and the
minimap, a journal window with fishing and gathering information, options, import from other
gathering addons and an optional data exchange with your guild.

## Saved data

All gathered data is account-wide (shared by all characters). Display settings will belong to the
active profile (Edit Mode layout) like in the other qn addons.
